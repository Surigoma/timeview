# 画面・タイマー・入力仕様

[仕様書の入口へ戻る](../SPECIFICATION.md)。本書は動作仕様の分冊。利用者向けの手順は[運用ガイド](../OPERATIONS.md)を参照する。

## 画面仕様

### 操作画面 `/`（`/control`も同じ画面）

- 起動後は操作画面を直接開く。残り時間、状態、演台表示のプレビューを表示する。
- 通常操作・設定・ログの切り替えはURL（`/`、`/settings`、`/logs`）と連動し、再読み込み・ブラウザの戻る／進むで対応する画面を表示する。現在の画面はナビゲーションの表示と`aria-current`で示す。
- 設定は「タイマー・表示」「定型文」「入力・外部連携」「バックアップ」にまとめ、タイマー・表示以外は初期状態で折りたたむ。設定・定型文の未保存編集と折りたたみ状態は、同一ページ内の画面切り替えで保持する。未保存編集は明示し、適用成功または編集取消で解除する。再読み込み・別ページへの移動では下書きを保持しない。
- 通常操作・タッチ画面の残り時間は通常時に明るい中立色を使い、警告・超過時は設定した警告色へ切り替える。演台の背景色設定には影響しない。
- 演台画面と設定画面を開く操作を用意する。
- 開始／再開、一時停止、リセット、+1分、-1分を用意する。
- 「暗転」「暗転解除」を別々のボタンとして配置する。操作画面は暗転せず、現在の暗転状態と残り時間を常時確認できる。プレビューは演台と同じ黒表示にし、その外側に「暗転中」を表示する。
- 持ち時間、警告時間、色、時間切れ点滅、ブラウザ操作限定、カンペを設定する。
- カンペの入力・送信、非表示、再表示、消去、最大9件の定型文を用意する。
- API連携用にエンドポイントのコピー機能を用意する。
- Keypadの有効状態、割り当て、最後の入力結果を常時確認できる。
- 設定・定型文・Keypad割り当てはJSONへ保存され、実行状態は再起動で初期化されることを設定画面に明示する。
- 接続中／再接続中／未接続を表示する。操作失敗は日本語で通知する。
- 未送信のカンペ入力と送信済みカンペを区別する。
- 実行中のリセットは画面ボタンで確認する。Keypadには別途誤操作対策を設ける。

### タッチ操作画面 `/touch`

- 司会者がタッチパネルから操作するため、タイマー、開始／一時停止、±1分、リセット、暗転、カンペ表示、定型文を一画面に配置する。
- タイマー操作、暗転・カンペ操作、定型文、演台接続状況の順に配置し、接続一覧の展開で主要操作を下へ押し出さない。
- タップ対象は通常の操作画面より大きくし、横長・縦長の画面では一列または二列に収める。
- 実行中のリセットでは通常の操作画面と同じ確認を行う。
- 設定編集とKeypad割り当ては設けず、通常の操作画面への導線を表示する。

### 演台画面 `/display`

- 操作部品を極力省き、残り時間とカンペを大きく表示する。
- 横長・縦長の画面に追従し、時間表示が領域からはみ出さないよう縮小する。
- 表示モードは「タイマーのみ」「タイマー＋カンペ」「カンペのみ」。モードはすべての演台画面に同期する。
- 演台画面には「待機中」「計測中」「一時停止」「時間超過」等の状態文字を表示しない。状態は操作画面で確認する。
- 残り時間の段階に応じて背景全体を通常色、第1警告色、第2警告色、時間超過色へ切り替える。時間とカンペの文字色は背景から白または黒を自動選択する。
- 画面下部に経過時間ゲージを表示する。ゲージ全体を通常・第1警告・第2警告の設定色で区切り、斜線の経過領域と現在位置を重ねる。直上に「第1警告まで 07:00」「第2警告まで 01:50」「終了まで 00:30」のように次の境界までの時間を表示する。無効値0の警告領域は表示しない。経過率は`(持ち時間 - 残り時間) / 持ち時間`を0～100%へ制限し、時間超過時は100%、残り時間加算で持ち時間を超えた場合は0%とする。
- 全画面への切り替えは画面内ボタンから行う。
- 通信断中は推定表示であることを示す小さな警告を出す。ただし暗転中は警告も表示しない。
- 通常のカンペはプレーンテキストとして表示し、HTMLは解釈しない。

### 設定画面 `/settings`

表示URLの確認・コピー、Keypad・MIDI割り当て、表示言語、システムログレベルの設定を行う。表示言語は日本語と英語から選び、設定保存後に接続中の全画面へ同期する。ログレベルは `debug`、`info`、`warn`、`error` から選び、保存と同時に稼働中のプロセスへ反映する。APIと画面の操作失敗メッセージは運用時の照合を優先して日本語のままとする。待受アドレスとポート、JSON設定ファイルの保存先は起動オプションで指定できる。

### 設定のバックアップ

設定画面末尾からJSON設定を書き出し・読み込める。形式は既存の設定ファイル（version: 1）と共通で、タイマー設定・定型文・Keypad/MIDI割り当てのみを含む。計測状態・残り時間・暗転・現在のカンペは含まない。

- UIはサーバー検証後に変更項目と現在／読込後の値を示す。確認後の適用には検証時点のETagを使い、途中の他の操作による上書きを防ぐ。計測中・一時停止中・接続断中は読込できない。
- エンドポイントとサイズ制限は[設定のバックアップAPI](API.md#設定のバックアップapi)に従う。

### 操作ログ画面 `/logs`

- 起動、正常終了、異常終了と変更操作の成否を一覧表示する。
- 最新500件を新しい順に表示する。SSEで自動更新し、再接続時に最新一覧を取得する。手動更新ボタンは設けない。
- カンペ本文、設定値、要求本文は表示・記録せず、操作種別と結果だけを扱う。

### 演台接続の一覧

- 通常操作・タッチ画面の演台一覧では「応答なし」の行だけに「一覧から削除」を表示する。対象IDと再応答時に再表示されることを確認して削除する。接続中の記録は削除できず、確認中に再接続した場合も拒否してエラーを表示する。
- 演台一覧の各行から名前を編集・保存・取消できる。名前は改行なし40文字以内、前後の空白を除去し、空欄で解除する。名前と短縮IDを併記し、削除確認にも名前を表示する。名前はメモリ内の接続記録に紐づき、同じIDの再応答では保持するが、演台ページ再読込（新しいID）・サーバー再起動・期限切れ・記録削除では解除する。
- 名前の横に編集アイコン、応答なしの行の右端に削除アイコンを配置する。両方に読み上げ用ラベルとツールチップを付け、保存・取消ボタンは編集中のみ表示する。
- 応答判定・保持期限は[演台ページの接続確認](API.md#演台ページの接続確認)に従う。

### 画面暗転（上映用）

- サーバーに真偽値`blackout`を持ち、接続しているすべての演台画面に同期する。端末別の暗転は初回の対象外。
- `blackout=true`では演台画面の描画領域全体を`#000000`で塗り、時間、カンペ、警告色、点滅、接続通知、ボタン、アプリ内カーソルを表示しない。全表示モードより暗転を優先する。
- 暗転と解除では時間、カンペ、ゲージ、通知、ボタン、カーソルを即時に非表示／再表示する。背景色は見た目を滑らかにするため180ms程度の短いフェードを許可する。暗転中のクリック・タップ・マウス移動では解除しない。解除は操作画面・API・Keypadから明示的に行う。
- 暗転は表示だけに作用する。実行中の計測は続け、一時停止中なら停止を維持する。時間切れやカンペ送信、start、pause、reset、表示モード変更で自動解除しない。
- 暗転中もカンペや設定を更新できる。解除すると、その時点の残り時間・警告・表示モード・カンペ表示フラグを反映する。暗転前のスナップショットには戻さない。
- サーバー起動・再起動時は`blackout=true`を既定とする。上映中の意図しない点灯を避け、設定確認後にオペレーターが解除する。
- 演台ページの初期HTMLと読み込み中の背景も黒とし、サーバーの最新状態を受信するまでコンテンツを出さない。通信断中は最後に受信した暗転状態を維持し、暗転中の再接続で一瞬コンテンツを表示しない。
- 演台ページで状態取得・再接続に失敗しても、エラーページへ自動遷移しない。初回取得前または暗転中は黒表示を維持する。再起動通知は操作画面側だけに表示する。
- 暗転APIの成功はサーバー状態の更新を意味し、すべての端末への描画完了を保証しない。未接続端末へは届かず、再接続後に最新状態を反映する。上映開始前に実際の表示を確認する。
- 対象はTimeViewの演台ページ。上映時は全画面表示を使用する。OS通知・ブラウザUI・他アプリやディスプレイ電源、プロジェクターのシャッターは制御しない。機器自体の黒レベルやバックライトによる発光は残り得る。

## タイマー仕様

### 値と状態

- 持ち時間: 1秒～24時間。UIは時・分・秒で入力、APIは整数秒。
- 既定値: 持ち時間600秒、第1警告180秒、第2警告60秒。
- 状態: `idle`（待機）、`running`（計測中）、`paused`（停止中）。
- 時間切れは独立した動作状態ではなく、残り時間が0以下という表示条件。
- `running`では時間切れ後も計測を続け、負の残り時間で超過量を表す。
- 内部計算はミリ秒。APIの残り時間も符号付きミリ秒で返す。

### コマンドと状態遷移

| コマンド | idle | running | paused |
| --- | --- | --- | --- |
| start | 現在の残り時間から開始 | 成功・変更なし | 現在の残り時間から再開 |
| pause | 成功・変更なし | その瞬間の残り時間で停止 | 成功・変更なし |
| reset | 持ち時間へ戻す | 停止し、持ち時間へ戻す | 持ち時間へ戻す |
| adjust | 待機中の残り時間を加減算 | 計測を維持して加減算 | 停止を維持して加減算 |

`reset`後の状態は常に`idle`。カンペ・表示モード・警告設定・暗転状態には影響しない。カンペ消去と暗転解除は独立した操作とする。

`adjust`は設定済みの持ち時間を変更しない。例えば持ち時間10分、残り5分で+1分を実行すると残り6分になり、後からresetすると10分に戻る。加減算は1回あたり±3600秒以内の非ゼロ整数とする。時間の減算で0を下回ることを許可する。操作で残り時間が±24時間を超える場合は422にする。自然経過による超過時間はこの制限で停止しない。

持ち時間の変更は`idle`のみ許可し、残り時間も新しい持ち時間にそろえる。`running`または`paused`での変更は409。警告時間と色、表示モードはどの状態でも変更できる。

### 警告・時間表示

警告は残り時間を基準とする。設定条件は `0 <= 第2警告 <= 第1警告 <= 持ち時間`。0秒指定の警告は無効。同値の場合は第2警告を優先する。持ち時間変更で条件を満たさなくなる場合は、警告値も同じ更新で修正するか422とする。

| 条件（上から優先） | 既定表示 |
| --- | --- |
| 残り時間 <= 0 | 赤系背景（既定`#ff6069`） |
| 第2警告が有効かつ残り時間 <= 第2警告 | オレンジ背景（既定`#ff9854`） |
| 第1警告が有効かつ残り時間 <= 第1警告 | 黄色背景（既定`#f2cc60`） |
| 上記以外 | グレー背景（既定`#4b5263`） |

時間切れ点滅は既定でOFF。ONでも緩やかな明暗変化とし、OSの動きを抑える設定を尊重する。警告音は初期対象外。

正の残り時間は秒未満を切り上げる。超過時間は絶対値の秒未満を切り捨て、1秒以上の超過からマイナスを付ける。時間切れ直後の1秒未満は`00:00`と時間超過表示にする。1時間未満は`MM:SS`、1時間以上は`H:MM:SS`。警告判定は丸める前の値で行う。

### 時間管理と復旧

- Go側を正とし、毎秒1ずつ減算せず、計測基準点と経過時間から残り時間を算出する。
- 稼働中の経過時間はGoの単調増加時計を利用し、OSの時刻補正による急なジャンプを避ける。
- API応答・SSEには、その時点の`remainingMs`、`state`、`serverTimeMs`、`instanceId`、`version`を含める。`instanceId`は起動ごとに生成するランダムID。
- Reactは受信時の値を基準に単調増加時計で補間し、次のサーバー情報で補正する。一定周期の減算値を正として保存しない。
- 通信遅延の補正には状態取得の往復時間を使う。同期精度は会場LANでの受入試験で確認する。
- 通常の状態配信は1秒間隔。操作成功時は直ちに配信する。
- 5秒間、新しい状態を受信できなければ通信断表示にする。暗転中の演台画面には通知を出さない。実行中ならローカル推定を継続し、操作は無効化する。
- 再接続時は最新スナップショットで置換する。通信断中の操作をキューに溜めて後で自動実行しない。
- サーバー終了・クラッシュ・再起動では実行状態を破棄する。次回起動は保存済みの持ち時間、警告、配色、点滅、表示モード、表示言語、定型文、Keypad割り当てを復元する。残り時間は持ち時間へ戻し、`idle`、カンペなし、`blackout=true`から開始する。以前の計測を復元・自動再開しない。
- 再起動後は同じURLへ自動再接続する。新しい`instanceId`を受け取った画面は旧状態と未完了要求を破棄する。操作画面には「サーバーが再起動し、初期化されました」と表示し、演台画面は暗転を優先する。`version`の大小比較は同じ`instanceId`内でのみ行う。
- サーバーPCのスリープは通常運用外。復帰後は再同期・状態確認を行う。スリープ中の表示同期は保証しない。

### 操作画面の終了予定時刻

通常操作画面とタッチ操作画面にサーバー時刻と残り時間から算出した終了予定時刻を秒単位で表示する。待機中は「今開始した場合」、一時停止中は「今再開した場合」と表記する。加減算を反映し、時間超過中は残り時間が0になった時刻を表示する。日付をまたぐ場合は月日も表示する。通信断中は時刻を「—」とし、演台画面には追加しない。

## カンペ仕様

- 最大500 Unicodeコードポイント、改行を許可する。過長入力は切り詰めず422で拒否する。
- 空文字の送信は消去として扱い、`visible=false`にする。
- 非空文字の送信は本文更新と`visible=true`を一括で行う。
- 非表示は本文を保持する。再表示は保持した本文を表示する。本文が空の場合の再表示は422。
- 消去は本文を空にし、非表示にする。
- 定型文は最大9件、各500文字以内。押すと即時送信する。
- 表示しきれない場合は文字サイズを所定の最小値まで縮小する。なお収まらない文面は操作画面で警告し、短く編集できるようにする。

## Keypad入力仕様

### 対応方式と制限

通常のキーボードイベントを送るUSBテンキー・プログラマブルKeypadを対象とする。ブラウザ利用時はドライバーやWebUSBを使わず、React操作画面の`keydown`からAPIを呼び出す。

ブラウザ入力は対象の操作画面が前面にあり、フォーカスを持ち、Keypad操作が有効なときにのみ受け付ける。他アプリ操作中やブラウザを最小化した状態では反応しない。OS全体で常時操作が必要な場合はUIなしリモコンの`listen`、その他はHTTP API方式を使う。

ブラウザでは複数の物理キーボードを識別しない。同じキーコードは同じ操作となる。Num Lockによる違いや機種固有のコードはキー登録画面で実測する。

### 既定割り当て案

| キー | 操作 |
| --- | --- |
| NumpadEnter | 開始／再開 |
| NumpadDecimal | 一時停止 |
| NumpadAdd | 残り時間 +60秒 |
| NumpadSubtract | 残り時間 -60秒 |
| Ctrl + Numpad0 | リセット |
| Numpad1～Numpad9 | 定型文1～9を送信 |
| Numpad0 | カンペ非表示 |
| NumpadMultiply | カンペ再表示 |
| NumpadDivide | カンペ消去 |
| Ctrl + NumpadSubtract | 暗転 |
| Ctrl + NumpadAdd | 暗転解除 |

開始と停止は独立したキーにし、再送や連打で状態が反転するトグル操作を初期仕様に設けない。

暗転と解除も独立したキーにする。修飾キーを含め完全一致で判定し、Ctrl付きの暗転操作が残り時間の加減算としても実行されることを防ぐ。

### 入力処理

- `KeyboardEvent.code`と修飾キーで照合し、登録操作で変更できる。
- `event.repeat`、IME変換中、入力欄・テキストエリア・編集可能領域への入力は無視する。
- 登録したキーに対してのみブラウザ既定操作を抑止する。
- Keypadは初期OFF。明示的にONにすると有効状態を強調表示する。
- ページ遷移、タブ非表示、ウィンドウのフォーカス喪失、通信断でOFFに戻す。
- 同一キーの300ms以内の重複入力を無視し、操作送信中は新しいKeypadコマンドを受け付けない。
- 割り当て競合は保存時に拒否する。リセットには修飾キーを必須とする。
- 「入力・外部連携」を閉じるとキー・MIDIの割り当て入力待機を解除する。閉じた後にMIDI接続処理が完了しても入力待機へ移行しない。割り当て・解除ボタンの読み上げ名には対象の操作名を含める。
- 割り当てはサーバーのJSON設定へ保存し、すべての操作画面で共有する。ページ再読み込みとサーバー再起動後に復元する。Keypadの有効状態は保存せず、各画面で常にOFFから始める。
- Windows・macOS・Linuxそれぞれでキーコード・修飾キーを確認する。macOSでも既定のリセットはControlキーを使い、Commandキーへの変更は登録画面で行う。
- ブラウザ予約キーや機種固有入力をすべて捕捉できる保証はしない。選定実機で受入確認する。
- UIなしリモコンの`listen`は、Windows、macOS、Linux（X11）で前面アプリに関係なくOS全体のキー入力を監視する。長押しはキー解放まで1操作とし、操作は抑止せず元のアプリにも渡す。macOSではアクセシビリティの入力監視許可を必要とし、LinuxのWaylandネイティブ環境は対象外とする。

### MIDI入力

- ブラウザ標準のWeb MIDI APIを使用し、対応ブラウザの操作画面から明示的に有効化する。
- MIDI LearnはNote On（`0x9n`）とControl Change（`0xBn`）を対象とし、チャンネルとノート／コントローラー番号を操作へ割り当てる。
- Note Off、velocity 0、CC value 0で押下状態を解除する。同じ入力が押下中に反復しても1回だけ操作する。
- 同じMIDI入力の重複割り当てを拒否する。割り当てはKeypad割り当てと同じJSON設定へ保存するが、MIDIの有効状態は保存しない。
- MIDI機器は操作画面を開くPCへ接続する。安全なコンテキストが必要なため、既定運用ではサーバーPCの`127.0.0.1`からChromeまたはEdgeで利用する。
- UIなしリモコンの`listen`は、リモコンPCに接続済みの全MIDI入力をgomidi/rtmididrv経由でブラウザなしに監視する。WindowsはWinMM、macOSはCoreMIDI、LinuxはALSAを使用する。Note Off、velocity 0、CC value 0で解放し、接続機器の変更時はリモコンを再起動する。
