# 受入条件

[仕様書の入口へ戻る](../SPECIFICATION.md)。以下は期待結果であり、全項目の確認完了を意味しない。実施日・確認方法・未確認事項は[動作確認結果](../VALIDATION.md)を参照する。

## 試験一覧

| ID | 試験 | 期待結果 |
| --- | --- | --- |
| A01 | 操作画面と複数の演台画面を開いて開始 | 全端末が同一タイマーの状態を表示する |
| A02 | 開始→停止→30秒待機→再開 | 停止中の30秒を計測時間に含めない |
| A03 | 同じstartを連続送信 | 計測開始時点をリセットしない |
| A04 | 同一起動中・10分以内に同じキーの+60秒要求を再送 | 1回だけ加算される |
| A05 | 残り時間が警告値と0を通過 | 演台の背景全体が規定順の色になり、超過しても計測継続 |
| A06 | 実行中にreset | idleとなり持ち時間へ戻る。カンペは保持 |
| A07 | USBテンキーを長押し | 1回だけ実行。テキスト入力中とフォーカス喪失時は実行しない |
| A08 | 分離LANの別端末からHTTPで画面とAPIへアクセス | ログイン・トークン・証明書の設定なしで表示・操作できる |
| A09 | ネットワークを10秒切断して再接続 | 断表示→最新状態へ復帰。古い操作を再生しない |
| A10 | 設定変更後、実行中にサーバーを再起動 | 保存済み設定を復元し、idle・持ち時間全量・カンペなし・暗転へ初期化。同じURLへ自動再接続し、新instanceIdを認識 |
| A11 | カンペにHTMLや501文字を送信 | HTMLを実行しない。文字数超過は422 |
| A12 | 同時に異なる設定を保存 | 古いversionの設定保存が412で拒否される |
| A13 | 同時に異なるキーで+60秒を2要求送る | ロックで直列化され、合計120秒加算。競合で更新が消えない |
| A14 | 別PC2台で表示し8時間運用 | 性能目標を確認でき、再接続後も同期する |
| A15 | 表示URLを複数端末で開く | URLの発行や端末登録なしで同じ状態を表示できる |
| A16 | 実機でNum Lock ON/OFF、修飾キーを確認 | 登録コードを確認でき、対象外入力で誤操作しない |
| A17 | ブラウザ再読み込み・新しい表示端末を接続 | サーバーの状態から現在時点を表示 |
| A18 | 残り時間を0以下へ減算、警告値を変更 | 丸め前の値で即時に表示条件を再計算 |
| A19 | 全配布対象OS／CPUで起動・API操作・終了 | 共通仕様どおり動作し、DBは作成しない。設定JSONと操作ログは指定先に保存する |
| A20 | 各対象OSのブラウザでKeypad入力・全画面・SSEを確認 | OS別の入力を登録でき、同じ操作結果になる |
| A21 | 再送抑止記録を上限まで増やす | 新規キーを429で拒否し、記録済みの再送を二重実行しない |
| A22 | 再起動前のETagで設定変更 | 412となり、初期設定を古い編集で上書きしない |
| A23 | 操作画面・API・Keypadから暗転／解除 | 接続中の全演台が切り替わり、操作画面は利用可能。同じ値の連打で反転しない |
| A24 | 実行中に暗転し30秒後に解除 | 計測が30秒進み、その時点の残り時間を表示する |
| A25 | 暗転中に時間切れ・カンペ送信・resetを実行 | 黒表示を維持。解除時だけ最新内容を表示する |
| A26 | 暗転中に通信断・再接続・ページ再読み込み | アプリ領域に通知や白背景、カンペが一瞬表示されない |
| A27 | 暗転中にサーバーを再起動 | 演台は黒を維持。自動再接続後も再起動時の暗転が有効で、明示解除が必要 |
| A28 | 各対象OSで暗転キーと修飾キーを確認 | 暗転だけが実行され、加減算されない |
| A29 | 開始前、警告10秒前、第1警告中、時間切れ、残り時間加算を表示 | ゲージが通常・第1・第2警告領域に分かれ、現在位置と次の警告までの時間を表示する。経過率は0～100%を超えず、演台に状態文字を表示しない |
| A30 | 設定、定型文、Keypad割り当てを変更して再起動 | JSONが妥当で、設定だけを復元する。計測状態、残り時間、暗転解除、送信中カンペは復元しない |
| A31 | 設定JSONへ未知フィールド、不正値、未対応バージョンを記入 | 起動を中止して原因を表示し、ファイルを上書きしない |
| A32 | ブラウザ操作限定を有効にして画面、Keypad、外部APIから変更 | 画面とKeypadは成功し、外部APIの変更は403。GETとSSEは継続し、無効化後は外部API変更も再び成功する |
| A33 | MIDI Learn後に同じNote／CCを押下・長押し・解放 | 対応操作を押下ごとに1回実行し、割り当てを再起動後も復元する |
| A34 | 各対象OS版リモコンの`listen`中に別アプリからテンキーを押す | 起動時にサーバーから取得した割り当てに対応する操作をキー解放ごとに1回実行する |
| A35 | 各対象OS版リモコンの`listen`中にMIDI Note／CCを押下・長押し・解放 | リモコンPCに接続した機器から対応操作を押下ごとに1回実行する |
| A36 | 通常・タッチ画面で開始、停止、加減算、日付またぎ、通信断 | 終了予定時刻の値と表記が状態に合い、切断中は「—」。演台には表示しない |
| A37 | 待機中に設定を書出・読込・差分確認・適用 | 設定だけを一括復元し、暗転・現在のカンペを保持。競合・不正JSON・保存失敗では適用しない |
| A38 | 計測中・一時停止中に設定バックアップを読込 | 読込・適用できず、既存設定と実行状態を保持する |
| A39 | 演台応答を停止し15秒・30分経過させる | 応答なし・記録削除がSSEへ反映され、追加GETのポーリングは不要 |
| A40 | 演台へ名前付け・空欄保存・再読込・再起動 | 名前を共有し、空欄で解除。新ID・再起動では保持しない。改行・40文字超過は拒否 |
| A41 | 応答なしの記録を削除、確認中に応答再開 | 削除を共有し、再接続済みなら409で拒否。後続の応答で再作成する |
| A42 | 通常画面でログ購読、操作、切断、再接続 | 最新500件を自動更新し、古いinstanceIdの一覧を表示しない |
| A43 | 設定を未保存のまま通常操作・ログへ移動し戻る | 下書きと折りたたみ状態を保持。再読み込みでは破棄。戻る／進むはURLに対応 |
| A44 | キー入力待機中に入力欄を折りたたみ、Tabを押す | 待機を解除し、Tabは通常のフォーカス移動。割り当てを変更しない |
| A45 | 支援技術でキー・MIDI割り当てと解除を参照 | 操作名を含むラベルで対象と待機状態を識別できる |

時間計算・再送抑止・競合・初期化は自動テストで確認する。Keypad実機、全画面表示、読みやすさ、ネットワーク断は手動確認を併用する。
